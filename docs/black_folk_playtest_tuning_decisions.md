# BLACK FOLK — PLAYTEST TUNING DECISIONS

## What changed

1. **6 encounters per normal session**, targeting 5–8 minutes.
2. Added **DISCOVER cards** so the game teaches before it quizzes. A new idea should not usually arrive as a test.
3. Renamed **WHY NOW → WHY THEN** so historical context cannot be confused with the optional present-day layer.
4. **THEN → NOW** remains the transfer mechanic for present-day application.
5. Never show more than **two standard multiple-choice screens in a row**.
6. Debate screens use **BEST FIT**, not winner language.
7. Boss round changed from an 'all of the above' question into a **matching challenge**.
8. Misses do not trigger punitive red screens or lost points. The idea simply returns sooner.
9. Added **three curated onboarding sessions** before fully adaptive sessions begin.
10. Every session ends with **KEEP THIS**—one short idea worth carrying away.

## First three sessions

### WHAT DOES FREEDOM REQUIRE?

### HOW DOES POWER MOVE?

**KEEP THIS:** Attention matters. Organization, leverage, and leadership determine what happens next.

## Visual pacing rule

One screen = one action. Large type. Generous whitespace. Answers should look like choices, not paragraphs. Reveal text should usually fit without scrolling.
