# BLACK FOLK — KNOWLEDGE MAP + WORDS V1

## What this adds

- A real knowledge graph for EXPLORE using the existing 44 curriculum nodes.
- Worlds, threads, debates, context, encounter-derived connections, and quotations all live in one graph.
- The map begins sparse and reveals itself through PLAY rather than showing a giant spiderweb immediately.
- WORDS are exact quotations and stay visually separate from our paraphrases.

## Recommended EXPLORE hierarchy

**World → Node → Core Idea → Why Then → Words → Connected To → Threads → Debates**

A quote discovered in PLAY is permanently added to the linked node. The player can also open a dedicated **WORDS** collection containing only quotations already found.

## Map progression

**LOCKED → DISCOVERED → CONNECTED → FAMILIAR → STRONG**

The map should not show mastery percentages. A node can subtly gain visual weight/clarity as knowledge deepens.

## Important implementation rule

Do not render all edges at once. The satisfying part is discovering the network. Show a connection when the player has encountered it, unlocked its thread/debate, or reached enough familiarity with both nodes.
